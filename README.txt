COURSE REPORT FILES PORTAL

1. Replace the sample staff names and courses inside index.html in the portalData section.
2. Put each PDF in the matching folder and use these exact filenames:
   - course-results.pdf
   - course-survey.pdf
3. Upload the complete folder contents to a GitHub repository.
4. Enable GitHub Pages from Settings > Pages.

Important: GitHub Pages is public. Do not upload confidential course results there. Use Supabase authentication and private Storage for confidential documents.
